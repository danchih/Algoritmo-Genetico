# Algoritmo-Genetico

### Descrição do Projeto
- Esse projeto tem como objetivo criar e explorar o uso de um algoritimo genético para solucionar o problema do caixeiro viajante. Nele estão envolvidos nossos conhecimentos de aprendizagem de máquina utilizando o Python como liguagem de programação.

### Status do Projeto: 
- Concluído.

### Funcionalidades:
- Calculo em dois cenários diferente:
  - Pontos Uniformemente Distribuídos
  - Círculo de Pontos (Benchmark)
- 
- Plotagem e atualizaçã automática dos gráficos para cada 10 gerações

### Acesso ao Projeto:
- Para acessar o projeto, basta baixar a versao da release no computador e executar o arquivo Projeto_Genetica.py
